Design Principles
=================
1. Separation of Concerns - 每个组件单一职责
2. Composability - 组件可自由组合
3. Extensibility - 添加新算法只需 ~100 行
4. Testability - 每个模块独立可测

Quick Start
===========
1. Install:  pip install -e recrl/
2. Test:     python test_recrl.py
3. Example:  python recrl/examples/train_grpo.py
4. Docs:     cat ARCHITECTURE.md
